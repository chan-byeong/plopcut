Save what you select.Find it when you need it.

Plopcut is a clipboard app for macOS. Keep only what you choose, add a note and tags, and store it as plain files on your Mac.

Download for macOS

Free · Version 1.0.0 · macOS 14 or later · Apple Silicon and Intel · Open source

The quickest way to keep what you read

Plopcut does not watch your clipboard. It reads the selection or the clipboard only when you ask it to save.

⇧⌘C
Capture selected text

Select in any app, press one shortcut

Select text and press ⇧⌘C. Plopcut reads the selection directly when it can, without touching your clipboard, and keeps the app, window title, and Chrome tab URL as the source.

The save popup fills in a title, so add a note and tags and press ⌘↩. To keep text or an image you just copied, choose Save Clipboard from the menu bar.

Find it again in seconds

Search titles, text, notes, tags, and sources at once. Narrow by website, such as github.com, or by app, such as Terminal, then by tag and date.

Read it the way it was written

Markdown shows its headings, lists, tables, and code blocks. Code is highlighted and has a copy button. If the format is guessed wrong, change it from the format menu. The saved file stays as it was.

Pin what you reuse, edit what changes

Pinned drops stay at the top of the list and in the Pinned collection. Pin with ⇧⌘P. Edit the text with ⌘E, and change the title, note, and tags in place; they save automatically.

Your drops are files, and they stay on your Mac

No database and no special format. Each drop is a folder you can read in any editor and back up with Time Machine.

  • No background monitoringThe clipboard and selection are read only when you save.
  • No network codeNothing is uploaded or synced, and there is no update check.
  • No account, no analyticsNo sign-in, crash reports, or usage tracking. This website has no analytics or cookies either.
  • MIT open sourceCheck the code yourself. See how the privacy claim is checked

What Plopcut asks for, and why

macOS asks the first time a feature needs a permission. You can check each one in Plopcut's Settings.

PermissionWhy
AccessibilityReads the text you selected in the app you are using. If that fails, it sends ⌘C and restores your clipboard afterward. Selected-text capture needs it.
System Settings › Privacy & Security › Accessibility
Automation (Chrome)Reads the URL of Chrome's active tab so the drop keeps its source link. Capture still works without it.
System Settings › Privacy & Security › Automation
ClipboardRead only when you choose Save Clipboard. Recent macOS versions may show their own prompt.

Up and running in a minute

Plopcut is signed with an Apple Developer ID and notarized by Apple, so it opens like any other app.

  1. DownloadGet Plopcut.dmg.
  2. Drag to ApplicationsOpen the disk image and drag Plopcut into Applications.
  3. Choose a folderOn first launch, keep ~/Documents/plopcut or pick another folder.
  4. Allow permissionsAllow Accessibility and Automation when macOS asks.
Updates. Plopcut never checks for updates. Download the new version here and replace the app. Your drops and settings stay where they are.
Verify the download. Each release lists its SHA-256 checksum. Compare it with shasum -a 256 Plopcut.dmg.
