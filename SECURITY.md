# Security policy

Plopcut keeps your drops on your Mac and sends nothing over the network. Its
permissions (Accessibility, Automation, clipboard) are still sensitive, so please
report problems privately.

## Reporting a vulnerability

Use GitHub's private reporting: open the
[Security tab](https://github.com/chan-byeong/plopcut/security/advisories/new) and choose
**Report a vulnerability**. Please do not open a public issue or pull request for a
security problem.

Include what you found, the Plopcut and macOS versions, and steps to reproduce.
You can expect a first reply within 7 days. We will work on a fix with you and credit you
in the release notes if you want.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: the Plopcut app, its on-disk handling of drops and settings, the
permission and capture code, and the release scripts. Out of scope: other apps
that Plopcut captures from, and macOS itself.
