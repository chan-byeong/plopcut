# 접근성 점검 (STA-80)

Linear: [STA-80](https://linear.app/byeoung/issue/STA-80)

코드로 VoiceOver 라벨·특성·순서와 키보드 이동을 점검하고 빈틈을 고쳤습니다. 실제 VoiceOver 확인은 사람이 해야 합니다(맨 아래).

## 점검 결과와 수정

| 화면 | 상태 | 조치 |
| --- | --- | --- |
| 저장 팝업 | 창 제목이 비어 VoiceOver가 창 이름을 못 읽음 | `panel.title`을 `saveText`/`saveImage`로 설정(제목 막대는 계속 숨김). 테스트 있음 |
| 저장 팝업 | 오류 문구가 나타나도 알리지 않음. 쓸모없던 `.isStaticText` | 오류가 생기면 `AccessibilityNotification.Announcement`로 읽어 줌 |
| 저장 팝업 | 머리글이 제목 특성 없음. `노트`, `태그` 캡션이 입력란 라벨과 중복 낭독 | 머리글에 `.isHeader`, 캡션은 보조 기술에서 숨김(입력란에 이미 라벨 있음) |
| 저장 팝업 | `출처` 라벨과 값이 따로 읽힘 | 한 요소로 묶음 |
| 저장 팝업 | 키보드: 열리면 태그 입력란 포커스, Tab으로 노트, `Cmd+Return` 저장, `Esc` 취소 | 이미 충족(테스트 `SavePopupNoteEditorTests` 등) |
| 라이브러리 | 목록 행이 제목·시간·미리보기·앱·태그를 각각 따로 읽음 | 행 하나를 `제목, 유형, 시간, 미리보기, 앱, #태그` 한 문장으로 읽음(`Formatting.rowAccessibilityLabel`) |
| 라이브러리 | 상세 제목 입력란에 라벨 없음, 이미지 미리보기에 라벨 없음 | `dropTitle`, `image` 라벨 추가 |
| 라이브러리 | 사이드바 `List` 라벨, 도구 막대 단추(`Label`), 필터 칩 라벨, `Cmd+F`, 패널 닫을 때 포커스 복귀 | 이미 충족 |
| 라이브러리 | 읽지 못한 드롭 경고가 영어 고정, 알림창 단추 `OK` 고정 | `unreadableDrops`, `ok` 키로 현지화 |
| 설정 | 권한 행을 `combine`하면서 안의 `시스템 설정 열기` 단추까지 묶여 VoiceOver로 누르기 어려울 수 있음 | 상태 문구만 묶고 단추는 밖으로 뺌 |
| 설정 | 단축키 입력란: 단추 + 라벨 + 값 + 힌트 | 이미 충족. 오류는 `.updatesFrequently` |
| 설정 | 저장 폴더·테마·캡처 확인 방식 | 시스템 컨트롤이라 라벨이 기본 제공됨 |

수정한 라벨 중 `Formatting.rowAccessibilityLabel`, 창 제목, 새 문구 키는 `AccessibilityAndCopyTests`가 검증합니다.

## 사람이 VoiceOver로 확인해야 하는 것

SwiftUI/AppKit이 만드는 접근성 트리와 낭독 순서는 코드만으로 확정할 수 없습니다. 아래는 자동화하지 못했습니다.

1. 저장 팝업: 열릴 때 창 이름과 포커스된 태그 입력란이 읽히는지, `Tab` 순서(태그 → 추가 → 칩 → 최근 태그 → 노트 → 취소 → 저장 또는 노트 → 태그)가 자연스러운지, 이미지 드롭에서 유형 분할 컨트롤 `텍스트`/`이미지`가 선택 상태와 함께 읽히는지, 저장 실패 시 오류가 즉시 낭독되는지.
2. 한글 입력기로 노트·태그를 입력할 때 VoiceOver가 조합 글자를 중복 낭독하지 않는지.
3. 라이브러리: 사이드바 → 목록 → 상세 → 인스펙터 사이 `Control+Option+화살표` 이동, 목록 행 낭독 문장과 선택 상태, 컨텍스트 메뉴(`VO+Shift+M`), 휴지통 확인 대화상자, 인스펙터 오버레이(좁은 창)가 열릴 때 포커스가 들어가고 닫을 때 목록으로 돌아오는지.
4. 필터 팝오버와 검색창(`Cmd+F`)에서 VoiceOver 포커스가 올바르게 이동하는지.
5. 설정: 단축키 입력란에서 `Space`로 녹음을 시작하고 키 조합이 낭독되는지, 권한 행 낭독 후 `시스템 설정 열기` 단추에 접근되는지, 상태 문구(`폴더를 변경했습니다` 등)가 갱신 때 낭독되는지.
6. 전체 키보드 접근(시스템 설정 > 키보드)을 켠 상태에서 도구 막대 단추와 모든 컨트롤이 `Tab`으로 닿는지.
7. 다크 모드·대비 증가·동작 줄이기에서 정보가 색에만 의존하지 않는지(권한 `권한 필요`는 문구로도 표시됨).
