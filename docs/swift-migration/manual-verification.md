# 수동 확인 체크리스트 (STA-75)

자동 테스트로 닫을 수 없어 사람이 실제 앱에서 확인해야 하는 항목을 이슈별로 모았다. 각 항목의 근거와 배경은 [behavior-checklist.md](behavior-checklist.md), [accessibility.md](accessibility.md), [performance.md](performance.md)에 있다. 확인한 항목은 `[ ]`를 `[x]`로 바꾸고, 결과를 해당 Linear 이슈에 남긴다.

## 0. 준비

실제 사용자 폴더를 건드리지 않도록 **복사본**과 임시 설정 파일로 실행한다.

1. 앱 빌드: `scripts/make-app.sh debug` → `NotedropApp/.build/Notedrop.app`
2. 연습용 저장소 만들기: 실제 폴더를 복사하거나(`cp -R ~/Documents/Notedrop /tmp/nd-copy`) 픽스처([README](fixtures/README.md))를 복사한다.
3. 복사본으로 실행(환경변수는 `open`으로 전달되지 않으므로 실행 파일을 직접 실행한다): `NOTEDROP_STORAGE_FOLDER=/tmp/nd-copy NOTEDROP_SETTINGS_FILE=/tmp/nd-settings.json NotedropApp/.build/Notedrop.app/Contents/MacOS/Notedrop`
4. 주의: 개발 빌드는 ad-hoc 서명이라 다시 빌드하면 손쉬운 사용 권한이 풀릴 수 있다. 권한이 안 먹으면 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 Notedrop을 지우고 다시 추가한다.
5. 끝나면 `/tmp/nd-copy`, `/tmp/nd-settings.json`을 지운다.

## 1. 저장소 호환성 (STA-77)

- [ ] 복사한 폴더로 실행하면 모든 Drop이 보인다. 깨진 `drop.json`이 있는 Drop만 경고로 건너뛴다.
- [ ] 각 Drop을 수정하고 저장한 뒤 `drop.json`을 열어 키 집합이 유지되고 빠진 값이 `null`로 쓰이는지 본다 (S-01).
- [ ] 새 Drop을 저장하고 폴더 이름(ID), 시각, 파일 구성이 규칙(S-05~S-11)에 맞는지 본다.
- [ ] 이미지 Drop(픽스처 사용)이 Library 본문에 보이고 수정 후에도 `image.png` 경로가 유지된다. (실제 폴더에는 이미지가 없다.)
- [ ] 원본 폴더에는 아무 변경이 없다 (`diff -rq ~/Documents/Notedrop /tmp/nd-copy` 확인은 복사 직후 기준으로).

## 2. 단축키 키 녹화 (STA-77, C-06 · C-08)

설정 → `선택 텍스트 단축키` 필드에서 진행한다. 기준 단축키는 Shift+Cmd+C.

- [ ] 1. 필드를 누르면 테두리가 강조되고 `키를 누르세요…`가 보인다. Shift+Cmd를 누르고 있으면 `Shift+Cmd+`가 보이고 떼면 안내로 돌아간다.
- [ ] 2. Shift+Cmd+K를 누르면 필드가 `Shift+Cmd+K`가 되고 `아직 저장하지 않았습니다…`가 보인다. 이때 다른 앱에서 텍스트를 선택하고 Shift+Cmd+C를 누르면 캡처되고 Shift+Cmd+K는 반응하지 않는다.
- [ ] 3. `저장`을 누르면 Shift+Cmd+K로 캡처되고 Shift+Cmd+C는 반응하지 않는다. 앱을 재실행해도 유지된다.
- [ ] 4. 녹화 중 K만 누르면 수식 키 안내, Cmd+-(빼기)나 숫자 키패드 키는 쓸 수 없는 키 안내가 나오고 녹화가 계속된다. Esc를 누르면 녹화가 끝나고 필드는 이전 값이다.
- [ ] 5. 녹화 중 Cmd+Q, Cmd+W, Cmd+,를 눌러도 앱이 종료되거나 창이 닫히지 않고 필드에 조합이 보인다. Cmd+Q를 길게 눌러도 종료되지 않는다. 저장하지 않고 `취소`.
- [ ] 6. Shift+Cmd+K를 고른 뒤 다시 녹화하면서 현재 단축키(Shift+Cmd+C)를 누르면 캡처나 팝업이 뜨지 않고, 필드는 `Shift+Cmd+C`, 미저장 안내는 사라지고 `저장`은 비활성이다.
- [ ] 7. 조합을 고른 뒤 저장하지 않고 사이드바에서 Library로 갔다가 설정으로 돌아오면 필드가 이전 단축키이고 이전 단축키로 캡처된다. `취소`도 같다.
- [ ] 8. 다른 앱이 쓰는 조합을 녹화하고 저장하면 등록 실패 문구가 나오고 필드는 이전 값, 이전 단축키가 동작한다.
- [ ] 9. 한글 입력 상태에서 녹화해도 영문 키 이름(예: `Shift+Cmd+K`)으로 기록된다.
- [ ] 10. 녹화 중 다른 Notedrop 창이나 다른 앱 창을 클릭하면 녹화가 끝나고, 그 창의 키 입력과 전역 단축키 캡처가 정상 동작한다.

## 3. 권한 누락과 오류 UX (STA-78)

- [ ] 손쉬운 사용을 끈 채 Shift+Cmd+C를 누르면 알림에 안내 문구와 `시스템 설정 열기`가 나오고, 누르면 손쉬운 사용 화면이 열린다.
- [ ] 권한을 허용하고 앱으로 돌아오면 설정 화면의 권한 상태가 갱신된다.
- [ ] 허용을 거부·취소한 뒤 나중에 다시 허용해도 정상 동작한다.
- [ ] Chrome 자동화를 거부한 상태에서 캡처해도 저장이 막히지 않는다 (URL만 빠진다).
- [ ] 저장 폴더를 읽기 전용으로 바꾼 뒤(`chmod -R a-w /tmp/nd-copy/drops`) 캡처·편집·삭제하면 오류 알림과 `설정 열기` 버튼이 나오고, 버튼이 설정 화면으로 이동한다. 끝나면 `chmod -R u+w`로 되돌린다.
- [ ] 이미지 쓰기가 실패했을 때 문구가 나온다.
- [ ] 시스템 언어를 한국어와 영어로 각각 바꿔 위 문구가 모두 맞게 보인다.
- [ ] (나중에, 정식 서명 뒤) 앱을 업데이트해 서명이 바뀌었을 때 권한이 초기화되면 안내가 이해되는지 본다.

## 4. 로컬 로그 (STA-80)

로그 위치: `~/Library/Logs/Notedrop/notedrop.log`. **정식 `.app` 번들로 실행했을 때만** 기록된다 (`swift run`이나 테스트는 기록하지 않는다).

- [ ] 처음 실행하면 시작 줄(버전, 빌드, macOS 버전)이 생긴다.
- [ ] 설정 정보 구역의 `Finder에서 로그 보기`가 파일을 선택해 Finder를 연다. 로그가 없으면 폴더가 열린다.
- [ ] 손쉬운 사용을 끄고 캡처하면 `permission_missing` 줄만 생기고 텍스트·경로·URL은 없다.
- [ ] 시스템 설정에서 권한을 바꾸고 앱으로 돌아오면 권한 변경 줄이 생긴다.
- [ ] 로그 폴더를 읽기 전용으로 만들어도 앱이 정상 동작한다.
- [ ] (선택) 로그가 1MB를 넘으면 `notedrop.log.1`이 생긴다.
- [ ] `Finder에서 로그 보기` 단추 문구가 한국어·영어에서 맞다.
- [ ] 로그 전체를 훑어 Drop 내용, 노트, 제목, 태그, 클립보드 내용이 한 줄도 없는지 확인한다.

## 5. 성능 (STA-80)

- [ ] `python3 scripts/generate-perf-library.py /tmp/nd-perf`로 5,000건을 만든다.
- [ ] `NOTEDROP_STORAGE_FOLDER=/tmp/nd-perf NOTEDROP_SETTINGS_FILE=/tmp/nd-perf-settings.json`로 앱을 실행해, 시작부터 목록이 보일 때까지 걸리는 시간을 잰다. 결과를 [performance.md](performance.md)에 적는다.
- [ ] 검색창에 빠르게 입력해도 입력이 끊기지 않는다.
- [ ] 목록을 끝까지 스크롤해도 끊김이 없다.
- [ ] 한글 검색 확인: 맥에서 복사한 파일 이름처럼 자모가 분리된 텍스트가 든 Drop이 완성형으로 검색되는지 본다 (새 검색 인덱스는 UTF-8 바이트 비교라 누락될 수 있다).
- [ ] 끝나면 `/tmp/nd-perf`, `/tmp/nd-perf-settings.json`을 지운다.

## 6. VoiceOver·키보드 (STA-80)

VoiceOver는 `Cmd+F5`로 켠다.

- [ ] 저장 팝업: 열릴 때 창 이름과 포커스된 태그 입력란이 읽힌다. `Tab` 순서(태그 → 추가 → 칩 → 최근 태그 → 노트 → 취소 → 저장)가 자연스럽다. 이미지 Drop에서 `텍스트`/`이미지` 선택 상태가 읽힌다. 저장 실패 시 오류가 즉시 낭독된다.
- [ ] 한글 입력기로 노트·태그를 입력할 때 조합 글자가 중복 낭독되지 않는다.
- [ ] Library: 사이드바 → 목록 → 상세 → 인스펙터 사이를 `Control+Option+화살표`로 이동할 수 있다. 목록 행이 제목, 유형, 시각, 미리보기, 앱, 태그 순으로 한 문장으로 읽힌다. 컨텍스트 메뉴(`VO+Shift+M`)와 휴지통 확인 대화상자가 동작한다. 좁은 창에서 인스펙터 오버레이를 열고 닫을 때 포커스가 올바르게 이동한다.
- [ ] 필터 팝오버와 검색창(`Cmd+F`)에서 포커스가 올바르게 이동한다.
- [ ] 설정: 단축키 입력란에서 `Space`로 녹화를 시작하고 키 조합이 낭독된다. 권한 행을 읽은 뒤 `시스템 설정 열기` 단추에 접근할 수 있다. 상태 문구가 갱신될 때 낭독된다.
- [ ] 시스템 설정 › 키보드의 `전체 키보드 접근`을 켠 상태에서 도구 막대 단추와 모든 컨트롤이 `Tab`으로 닿는다.
- [ ] 다크 모드, 대비 증가, 동작 줄이기에서 정보가 색에만 의존하지 않는다.
